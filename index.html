Bookmarklet — Inject Auto-Fill ke Si-MASTER

Drag tombol ini ke bookmark bar browser Anda.
Saat berada di halaman Si-MASTER (halaman realisasi atau Tambah Aktivitas), klik bookmarklet untuk memunculkan panel auto-fill.

e-MASTER Auto Fill

  1. Import data (Excel/JSON) di tab 1
  2. Drag tombol biru di atas ke bookmark bar
  3. Buka Si-MASTER dan login (NIP + Password + OTP)
  4. Buka halaman Aktivitas Bulan → klik icon kunci pas pada breakdown
  5. Klik bookmarklet di bookmark bar
  6. Panel auto-fill muncul — pilih breakdown → klik Mulai Auto Fill

Atau: Copy-Paste ke Console

Jika bookmarklet tidak bisa di-drag, copy kode di bawah lalu paste di Developer Console (F12 → Console) saat di halaman Si-MASTER.
