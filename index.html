E-MASTER AutoFill — Browser Version

Auto-fill form Aktivitas Harian SKP di Si-MASTER BKD Jatim — tanpa perlu Tampermonkey

Cara Pakai:
1. Buka Si-MASTER di tab/window lain dan login manual
2. Navigasi ke halaman Aktivitas Harian (SKP → Realisasi Bulanan → Aktivitas Harian)
3. Kembali ke halaman ini, pilih template / isi kata kunci, lalu klik "Buka & Isi via Bookmarklet"
4. Atau gunakan Bookmarklet di bawah untuk inject skrip langsung ke halaman Si-MASTER

Bookmarklet (Drag ke Bookmark Bar)

Drag tombol ini ke bookmark bar browser Anda. Saat berada di halaman Si-MASTER, klik bookmarklet untuk memunculkan panel AutoFill.

E-MASTER AutoFill

  1. Drag tombol biru di atas ke bookmark bar
  2. Buka Si-MASTER dan login
  3. Navigasi ke halaman form Aktivitas Harian
  4. Klik bookmarklet di bookmark bar
  5. Panel E-MASTER AutoFill akan muncul
